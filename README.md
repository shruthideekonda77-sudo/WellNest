# 🌸 WellNest – Mental Wellness Application

WellNest is a Python-based mental wellness application designed to support users in maintaining their emotional well-being through mood tracking, personal journaling, goal management and personalized suggestions.

## ✨ Features

- **User Authentication:** Sign up and sign in functionality.
- **Dashboard:** A simple and interactive wellness dashboard.
- **Mood Tracker:** Record and monitor daily moods.
- **Personal Journal:** Write and save personal thoughts.
- **Goal Management:** Create and track personal goals.
- **Mood-Based Suggestions:** Get suggestions according to your mood.
- **Creative UI:** Lavender, pink and cream theme with cute animal and fantasy characters.

## 🛠️ Technologies Used

- Python
- Tkinter
- JSON
- File Handling

## 🚀 How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the application:

```bash
python wellnest.py
```

## 🎯 Project Objective

The main objective of WellNest is to encourage emotional awareness, healthy habits and personal growth through a simple and user-friendly desktop application.
